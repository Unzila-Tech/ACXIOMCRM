The system provides secure user authentication, role-based access control, a dashboard with business insights, customer and lead management, opportunity tracking, follow-up scheduling, activity management, and reports
Key Features:
User Registration and Login
Role-Based Access (Admin, Manager, Sales Executive)
Dashboard with CRM Statistics
Customer Management (Add, View, Edit, Deactivate)
Lead Management and Lead Tracking
Opportunity Management (Open, Won, Lost)
Follow-Up Management
Activity Management
Reports and Analytics
Audit Logging
REST API Integration
MongoDB Database Storage
Technology Stack:
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
ODM: Mongoose
Authentication: Secure Authentication and Role-Based Authorization
